Rental House Management System

1. Project Description

The Rental House Management System is a web-based application designed to simplify the management of rental houses. It helps landlords manage properties, tenants, rent payments, and maintenance requests.

2. Problem Statement

Finding a suitable house for rent can be difficult and time-consuming, especially for people who are new to a town. Traditional rental management also creates difficulties in tracking rent payments, managing tenants, and identifying vacant houses.

3. Objectives

- To help tenants find available rental houses.
- To help landlords manage their properties.
- To maintain tenant records.
- To monitor rent payments and outstanding balances.
- To track vacant and occupied houses.
- To manage maintenance requests.

4. Main Features

- User registration and login.
- Available house listings.
- Tenant management.
- Rent payment monitoring.
- Maintenance request management.
- Property and payment reports.

5. Technologies

The project is planned to use:

- HTML
- CSS
- JavaScript
- PHP
- MySQL

6. Project Status

The project is currently under development.
